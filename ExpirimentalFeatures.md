# Experimental features
---
This lists the features that are supported in this fork, but not the raylib upstream repository


PixelFormat Uncompressed 32bit Int (red channel)
LoadRenderTextureEx, with pixel and depth buffer formats
Detect Max Vertex Arrays
GPU skinning on by default
Dynamic GPU Skinning
Set ScreenShot Key
User Data for Audio Callbacks
Render Loop via callback with support for on drag and on size updates
Raymath and raylib in any include order
gltf buffer leak fixes
